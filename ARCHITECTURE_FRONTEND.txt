================================================================================
          PROPOSITION D'ARCHITECTURE FRONTEND FLUTTER - PROJET LADAFURA
                 Conforme au Cahier des Charges Officiel (INRMPT Mali)
================================================================================
Architecture modulaire : CORE / SHARED / FEATURES
Gestionnaire d'état : Riverpod (recommandé) ou Bloc
Client HTTP : Dio (avec Intercepteur Firebase JWT & retry réseau)
Navigation : GoRouter (déclarative, avec RouteGuard par rôle)

RÉPARTITION STRUCTURELLE :
- CORE/     : Infrastructure, configuration technique, réseau, routage, services de base
- SHARED/   : Modèles transversaux, énumérations, widgets et composants UI partagés
- FEATURES/ : Modules métiers spécifiques aux 3 acteurs mobiles (Population, Agent, Pharmacopée)

NOTE D'ARCHITECTURE MAJEURE :
Le rôle ADMINISTRATEUR (US-25 à US-32) est géré sur un portail Web dédié ANGULAR.
L'application FLUTTER implémente EXCLUSIVEMENT les 3 acteurs mobiles :
  1. POPULATION (Citoyens)           : US-01 à US-12
  2. AGENT DE COLLECTE (Terrain)     : US-13 à US-17
  3. PHARMACOPÉE (Officines)         : US-18 à US-24
